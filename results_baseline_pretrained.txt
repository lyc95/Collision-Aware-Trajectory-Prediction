================================================================
Metric definitions
================================================================
ADE           : Average Displacement Error (L2), best-of-20 per-ped,
                averaged over all peds in the test set. (minADE_20)
FDE           : Final Displacement Error (L2) at t = T_pred,
                best-of-20 per-ped, averaged. (minFDE_20)
ColRate_avg   : Fraction of the 20 samples (per scene) that contain
                ANY pairwise collision (dist < 0.2 m at any frame,
                any pair), averaged over all test scenes.
ColRate_minADE: For each scene, the sample that achieves minimum
                scene-level ADE is selected; ColRate_minADE = 1 if
                that sample contains any collision, 0 otherwise.
                Reported as the average across test scenes.

================================================================
Key observations
================================================================
1. Collision rates scale with scene density:
     Sparse scenes  (ETH, ZARA1):   ~ 7-15%
     Dense scenes   (UNIV, ZARA2):  ~ 42-87%
   UNIV (the densest scene) shows an 87% average collision rate -
   nearly every sampled prediction contains a pedestrian collision.

2. ColRate_minADE ~ ColRate_avg.
   The best-ADE sample is no safer than any other sample. The model
   has no implicit preference for collision-free predictions.

3. Motivation for this project is confirmed:
   Average collision rate across all 5 scenes is ~33%. One in three
   predicted trajectories contains at least one collision, despite
   strong ADE/FDE performance (0.45/0.76).

================================================================
Target for collision-aware training
================================================================
Maintain ADE ~ 0.45 and FDE ~ 0.76 while driving ColRate_avg from
33% down to single digits (target: <= 10% average).
UNIV (87% -> <20%) expected to be the most dramatic improvement.
